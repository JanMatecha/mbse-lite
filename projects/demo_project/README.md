# Demo Project

This project is intentionally generic. Its purpose is to demonstrate the MBSE-lite data model and tool chain, not to represent a production design.

## Demo goal

Develop an early concept for a small portable technical device that provides adjustable illumination for a work area.

## Workflow demonstrated

```text
Need -> Requirement -> Function -> Concept/Part -> Verification
```

Project decisions, risks and tasks are linked to the engineering model through explicit relations.
