# Codex Instructions — Demo Project

## Purpose

This project is a generic regression fixture for MBSE Lite. It demonstrates the supported Markdown model and is used by automated tests.

## Rules

- Keep the project generic and free of real private, customer or confidential information.
- Do not turn this directory into a real engineering project.
- Preserve enough objects and relations to exercise parser, validation and export behavior.
- Changes should remain small and understandable.
- If the application model contract changes, update this fixture only to represent the documented contract, not to hide application bugs.
- Do not copy content from any other project into this fixture.

## Source of truth

The Markdown files in this directory are authoritative for this demo model. Generated outputs are disposable.
