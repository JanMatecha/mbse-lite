# Garden Tool Shed

First real MBSE-lite project used to develop and validate the method on a private technical project.

## Project goal

Develop a sufficiently complete concept and technical definition for a garden tool shed so that it can proceed into detailed design and construction.

## Current phase

Initial problem definition and requirements capture.

## Source of truth

The Markdown files in this directory are authoritative project data. Generated HTML, Mermaid and XLSX files are views or exchange formats only.

## Working rule

Do not invent dimensions, materials, loads, budget, legal constraints or other technical facts. Unknown values must be recorded as `TBD` or as an `ISSUE` until confirmed.

## Main model files

- `01_needs.md`
- `02_requirements.md`
- `03_functions.md`
- `04_architecture_and_concepts.md`
- `05_verification.md`
- `06_project_management.md`
- `07_relations.md`

The structure may be extended when the project needs additional dedicated files such as site data, calculations, drawings, BOM or construction planning.
