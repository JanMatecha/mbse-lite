# Architecture and Concepts

## Logical parts

| ID | Name | Description | Status |
|---|---|---|---|
| PART-001 | Storage enclosure | Overall shed enclosure providing protected internal volume. | Draft |
| PART-002 | Access element | Logical element that allows entry to the storage volume. | Draft |
| PART-003 | Site interface | Logical element that supports the structure and interfaces with the ground/site. | Draft |
| PART-004 | Main storage zone | Primary storage area for long-handled tools, heavy hand tools, small garden tools, flower pots and hoses. | Draft |
| PART-005 | Enclosed mower compartment | Dedicated enclosed compartment for the battery lawn mower, physically separated from the main storage zone. | Draft |
| PART-006 | Internal storage system | Shelves, hooks, holders, bins, hose support or equivalent elements used to organize the mixed-size inventory. | Draft |
| PART-007 | Human access / standing zone | Clear internal space reserved for entry, standing and practical manipulation of stored items. | Draft |

## Concepts

| ID | Name | Description | Status |
|---|---|---|---|
| CON-001 | Ground-screw support | Support the shed on ground screws so a permanent concrete foundation is not required and the site interface can be removed/reinstalled if the shed is relocated. | Selected |
| CON-002 | Elongated narrow shed layout | Develop the shed around a target external footprint of approximately 4.0 m × 1.2 m, with storage arranged to preserve a usable access zone. | Candidate |
| CON-003 | Split internal storage layout | Divide the usable volume into a main tool-storage zone and a dedicated enclosed battery-mower compartment. | Selected |

## Decisions

| ID | Name | Decision | Rationale | Status |
|---|---|---|---|---|
| DEC-001 | Select ground-screw foundation concept | Use ground screws as the site support concept. | Avoids a permanent concrete foundation and supports the requirement that the shed can be relocated. | Accepted |
| DEC-002 | Separate mower compartment | Reserve a physically separate enclosed compartment for the battery lawn mower. | This is an explicit user requirement and separates the mower from the main mixed-tool storage space. | Accepted |

The exact structural material, roof form, door arrangement, mower-compartment dimensions, internal clear height and storage-system details remain open for concept development.
