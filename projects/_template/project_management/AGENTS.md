# Codex Instructions — Project Management Area

## Scope

This directory contains project execution planning and tracking, not the technical system definition.

## Rules

- Keep `TASK-*`, `MS-*`, owners, estimates, deadlines and progress here.
- Project/delivery risks or issues may live here when they concern execution rather than the technical system.
- Reference MBSE object IDs rather than copying engineering facts.
- Use `03_relations.md` for work-to-engineering traceability.
- Do not redefine technical requirements, architecture or verification here.
