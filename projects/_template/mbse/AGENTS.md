# Codex Instructions — MBSE Area

## Scope

This directory contains the technical/system model.

## Rules

- Keep needs, requirements, functions, architecture, concepts, technical decisions and verification here.
- Keep engineering issues and technical risks here.
- Keep supporting technical data here when it directly informs the system model.
- Do not place owners, deadlines, estimates or milestone tracking here.
- Preserve stable IDs and explicit engineering relations.
- Do not invent technical facts; use `TBD` or an engineering `ISSUE-*` when information is missing.
- When adding a requirement, consider how it will be verified.
